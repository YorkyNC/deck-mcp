# deck-mcp

MCP-сервер, который превращает описание в красивую презентацию (reveal.js HTML).
Контент придумывает твой ИИ-ассистент (Claude), сервер — красиво рендерит и публикует.

**Что умеет:** 12 лейаутов (карточки с иконками, ряды KPI, графики bar/donut/line,
фоновые изображения, разделители), 3 темы (тёмная / светлая / журнальная).
**Анимация включена по умолчанию:** контент появляется каскадом, цифры отсчитываются
от 0, графики рисуются, фон дышит. Всё self-contained: только reveal.js и Google Fonts
по CDN, никаких сборок и зависимостей в выходном HTML.

## Установка (для пользователей)

Нужен Node.js 18+ и любой MCP-клиент (Claude Code, Claude Desktop и т.п.).

**Claude Code:**
```bash
claude mcp add deck-mcp -- npx -y deck-mcp
```

**Claude Desktop** — в `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "deck-mcp": { "command": "npx", "args": ["-y", "deck-mcp"] }
  }
}
```

Перезапусти клиент. Проверка (Claude Code): `claude mcp list` → `deck-mcp ✓`.

## Как пользоваться

Ты не пишешь JSON и не вызываешь инструменты руками. Ты **описываешь презентацию словами**,
а ассистент сам собирает структуру, вызывает `create_deck` → `render_html` и отдаёт ссылку.
Готовый HTML лежит в `~/deck-mcp-output/<deckId>/index.html` (путь меняется через `DECK_MCP_OUT`).
Открой его в браузере, листай стрелками. Анимация запускается сама на каждом слайде.

### Как формулировать промпт (чем конкретнее — тем лучше)
Хороший запрос содержит: **тему · аудиторию · число слайдов · тему оформления · какие данные показать.**

> Сделай питч-дек на **10 слайдов** для инвесторов про сервис аренды спецтехники.
> Тема **aurora**. Нужно: обложка с фото, проблема, решение, слайд с **3 KPI**,
> график роста выручки по кварталам (bar), воронка клиентов (donut), команда карточками, CTA.

> Презентация для отдела продаж, тема **minimal**, **8 слайдов**, много цифр:
> big-number «**+247%**», сравнение было/стало, таблица тарифов карточками.

Чем больше конкретных **цифр** ты дашь (или попросишь придумать реалистичные) —
тем эффектнее: числа отсчитываются, графики рисуются. Избегай сплошного текста.

### Полезные приёмы
- **«переделай слайд 4 в график»**, **«поменяй тему на editorial»**, **«добавь слайд с командой»** — ассистент правит деку и перерендеривает.
- **«опубликуй»** — вызовет `deploy` (нужен `vercel login`), вернёт публичную ссылку.
- **«без анимации»** — соберёт статичную версию (`motion:false`), например для печати/PDF.

## Темы (стиль-паки)
| Тема | Стиль |
|------|-------|
| `aurora` | Тёмный премиум-питч, свечение, Manrope |
| `noir` | Глубокий чёрный, холодный акцент, сильное затемнение — максимум драмы |
| `minimal` | Светлый корпоративный, чистый фон, Inter |
| `editorial` | Журнальный, серифные заголовки Fraunces, тёплый фон |

## Анимация
Работает **автоматически**, включать не нужно:
- контент каждого слайда появляется каскадом (заголовок → буллеты/карточки волной);
- цифры (`metrics`, `big-number`) отсчитываются от 0;
- графики рисуются (столбцы растут, линия чертится, пончик закручивается);
- в теме `aurora` — живое свечение на фоне.

Флаги (ставит ассистент по просьбе):
- `hero: true` на слайде — оживлённый тёмный фон с затемнением на этом слайде (в любой теме); идеально для title/section/cover.
- `motion: false` на деке — полностью статично (печать/PDF).
- `animate: true` на слайде — буллеты/карточки по клику, а не сразу (для докладов).
- `morph: true` на **двух соседних** слайдах — общий элемент плавно перетекает между ними.

Уважается системная настройка «уменьшить движение» — тогда всё статично.

## Инструменты

| Инструмент | Что делает |
|------------|------------|
| `list_templates` | Список стиль-паков (`aurora`, `minimal`, `editorial`) |
| `create_deck` | Сохраняет структуру презентации (deck-JSON), отдаёт `deckId` |
| `render_html` | Рендерит `deckId` в самодостаточный reveal.js HTML |
| `deploy` | Best-effort публикация на Vercel (нужен `vercel login`) |

## Лейауты слайдов
`title` · `section` · `bullets` · `two-column` · `cards` (сетка фич с иконками) · `metrics` (ряд KPI) · `chart` (bar/donut/line) · `big-number` · `image-split` · `image-cover` · `quote` · `closing`

Иконки для `cards`: `rocket, chart, users, check, star, bolt, shield, target, clock, globe, cog, heart, lock, trend, money, layers, cloud, code, mail, spark, arrow, grid, database, eye, flag`.

## Разработка
```bash
npm install
npm run demo   # self-check + превью всех тем в ./decks/demo/{,minimal,editorial}/index.html
```

## Публикация в npm (для мейнтейнера)
Имя `deck-mcp` может быть занято — при необходимости используй scope, напр. `@yourname/deck-mcp`.
```bash
npm login
npm publish --access public
```
После публикации команда установки выше заработает у всех.
